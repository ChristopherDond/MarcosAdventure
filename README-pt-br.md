# ⚔️ Marcos Adventure

> *"Todo grande herói precisa de um grande vilão — e aqui temos três."*

---

## Sobre

**Marcos Adventure** é um jogo de ação construído inteiramente com HTML — sem frameworks, sem dependências, apenas energia pura de front-end.

O jogador enfrenta **3 chefes épicos**, cada um baseado em um adesivo do próprio professor, em batalhas cada vez mais brutais. É educativo. *De certa forma.*

> ⚠️ **Aviso:** Nenhum professor foi ferido durante o desenvolvimento deste jogo. Emocionalmente, talvez.

---

## Jogabilidade

- **3 chefes únicos** — cada um com seu próprio comportamento, visual e dificuldade
- **Sistema de combate direto** — você contra o professor
- **Fases progressivas** — derrote um chefe para desbloquear o próximo
- **100% baseado no navegador** — sem instalação, sem configuração, é só abrir e jogar

---

## Começando

Você não precisa instalar nada. Literalmente.

```bash
# Clone o repositório
git clone https://github.com/ChristopherDond/MarcosAdventure.git
cd MarcosAdventure

# Abra o index.html no seu navegador
# (ou apenas arraste o arquivo para o navegador, também funciona)
```

## Stack Tecnológico

- **HTML5** — estrutura do jogo
- **CSS3** — animações e estilo visual
- **JavaScript (Vanilla)** — lógica do jogo, colisões e comportamento dos chefes

Sem bibliotecas externas. Zero dependências. Front-end puro de guerrilha.
